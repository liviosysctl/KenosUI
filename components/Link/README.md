# Link

Inline text link: `fg` text with a thin `accent-border` underline that turns `accent-fg` and thicker on hover — the red, on purpose.

**Variants** `underline` (default, in text) · `plain` (no underline until hover: table cells, nav-like lists). `external` opens a new tab and adds the external-link icon. Markdown links render as this; `http(s)` links are external automatically.

**Consumer provides** `href` and the text.
