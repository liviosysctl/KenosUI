# CommandPalette

Ctrl/⌘+K search over pages and actions: grouped, fuzzy-ish filtering (accents ignored, prefix first), ↑↓ Enter, shortcut hints. Opens as a Dialog (bottom sheet on phones). **Consumer provides** `items` (`label`, `group`, `icon`, `description`, `keywords`, `shortcut`, `onSelect` or `href`), optionally `open`/`onOpenChange`, `hotkey` (default `mod+k`).
