# Heading

Section and page titles in Inter 600, sizes from the type scale.

**Sizes** `4xl` (h1, page title) · `3xl` (h2) · `2xl` (h3) · `xl` (h4, default) · `lg` (h5) · `md` (h6); the HTML tag follows the size unless `as` is set. Markdown `#`…`######` renders as exactly these.

**Consumer provides** the text; `as` when the outline level differs from the visual size.

- Do: one `4xl`/`2xl` page title per screen (apps usually use `2xl`), sentence case.
