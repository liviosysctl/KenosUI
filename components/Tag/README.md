# Tag

Compact label for things attached to an object: profiles, images, projects, networks, architecture — optionally with icon and remove button.

**Variants** like Badge (`subtle` default, `solid`, `outline`, `surface`); **sizes** 18 / 20 / 24 / 32px. Tag = an attribute you may remove; Badge = a status or count.

**Consumer provides** text, optional `icon`, `onClose`. In Markdown: `:tag[debian/12]{icon=layers}`.
