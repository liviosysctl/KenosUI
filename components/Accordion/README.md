# Accordion

Collapsible sections on native `<details>`: open/close works without JS, one-at-a-time via the `name` attribute unless `multiple`.

**Variants** `outline` (hairlines, default) · `enclosed` (framed, open item on `bg-subtle`) · `subtle`. Use for advanced settings groups.

**Consumer provides** `items` (`value`, `title`, `content`, optional `icon`), `defaultValue`.
