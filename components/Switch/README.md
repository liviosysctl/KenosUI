# Switch

On/off toggle that takes effect immediately (settings), not a form choice to submit later.

**Checked** track is `primary-solid` (black; white in dark) or `accent-solid` with `palette="accent"`; unchecked is `bg-emphasized`. **Sizes** `xs` 24×12 · `sm` 32×16 · `md` 40×20 (default) · `lg` 48×24. Native checkbox underneath (`role="switch"`), focus ring `focus-ring`.

**Consumer provides** `label`, `checked`/`onChange` (or `defaultChecked`).
