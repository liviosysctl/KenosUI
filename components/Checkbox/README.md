# Checkbox

Square checkbox (native input) with label and optional description; supports indeterminate.

**Sizes** box 16 (`sm`) · 20 (`md`, default) · 24px (`lg`). Checked fills with `primary-solid` (or `accent-solid`); the tick flips to black in dark mode. Markdown task lists (`- [x]`) and Table selection use the same box.

**Consumer provides** `checked`/`onChange` (or `defaultChecked`), `label`, optional `description`, `indeterminate`.
